# Story & Script

Working title: **Chip Heist** — a 2–4 player co-op Roblox heist parody.
Every player is "Sam" (a parody of Sam Altman) breaking into a Discord
mod's house to steal RAM sticks and GPUs "for the data center".

## Folder layout
| Path                | What goes here                                              |
|---------------------|-------------------------------------------------------------|
| `research/`         | Background research (real-world context, memes, setting)    |
| `story-bible.md`    | Characters, tone, world, house layout, scene list           |
| `scenes/`           | One file per scene / cutscene: `NN-short-name.md`           |
| `dialogue/`         | Barks and reusable lines (mod reactions, Sam quips, NPCs)   |

## Scene file template
```
# NN — Scene name
Type: cutscene | gameplay | cutscene+gameplay
Location:
Players: what each of the 1–4 Sams is doing
Camera / cuts:
Beats:
Dialogue:
Trigger in / trigger out:
Implementation notes (Roblox):
```
